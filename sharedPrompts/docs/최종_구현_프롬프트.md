You are a senior Java Spring Boot backend engineer performing a safe architectural refactor.

The codebase contains a prompt generation engine under:

src/main/java/org/example/sharedprompts/domain/prompt

All package names below are relative to this domain prompt package (e.g. adapter.in.web.controller =
org.example.sharedprompts.domain.prompt.adapter.in.web.controller).

The current system performs semantic resolution and prompt generation in a single request:

POST /prompts/generate

This mixes:
- recommendation
- fallback
- confirmation
- final generation

The goal of this refactor is to introduce a **recommendation-first architecture** while preserving backward compatibility.

The system must support two flows:

1️⃣ Quick one-shot generation (existing behavior)

POST /prompts/generate  
→ resolve semantics  
→ generate prompt

2️⃣ Recommendation-first flow (new behavior)

POST /prompts/recommend  
→ return recommended semantic axes

User selects / confirms

POST /prompts/generate/confirmed  
→ generate using confirmed axes only

The existing one-shot flow must remain fully functional.

- objective / output_needs: RECOMMENDED when derived from IntentDictionary.
