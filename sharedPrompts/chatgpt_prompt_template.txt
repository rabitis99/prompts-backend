다음 카테고리별로 AI 프롬프트를 생성해주세요.

카테고리: [카테고리명]
카테고리 설명: [카테고리 설명]
생성 개수: [개수]개

요구사항:
1. 각 프롬프트는 실제로 사용할 수 있는 구체적이고 실용적인 내용이어야 합니다.
2. 제목은 명확하고 간결하게 (10-50자)
3. 설명은 프롬프트의 목적과 사용 방법을 설명 (50-300자)
4. 내용(content)은 실제 AI에게 전달할 프롬프트 텍스트 (20-500자, 주로 영어)
5. 다양한 주제와 접근 방식을 포함하여 중복을 피하세요.

출력 형식 (JSON 배열):
```json
[
  {
    "title": "프롬프트 제목",
    "description": "프롬프트 설명",
    "content": "실제 프롬프트 내용",
    "category": "카테고리명"
  }
]
```

카테고리별 가이드라인:

[PRODUCTIVITY]
- 업무 효율 향상, 시간 관리, 자동화, 프로세스 개선
- 일정 관리, 우선순위 설정, 집중력 향상, 습관 형성

[DEVELOPMENT]

[CODING]
- 깨끗한 코드 작성, 디자인 패턴, 리팩토링
- 버그 수정, 코드 최적화, 모범 사례

[PROGRAMMING]
- 프로그래밍 언어 학습, 알고리즘, 자료구조
- 코드 예제, 문법 질문, 개념 설명

[ANALYSIS]
- 데이터 분석, 통계, 인사이트 도출
- 비즈니스 분석, 트렌드 분석, 문제 해결

[MARKETING]
- 마케팅 전략, 브랜딩, 광고, 시장 조사
- SEO, 디지털 마케팅, 고객 분석

[CONTENT]
- 블로그, SNS, 영상 콘텐츠 기획 및 작성
- 콘텐츠 아이디어, 스토리텔링, 매체별 최적화

[CREATIVE]
- 창의적 아이디어, 스토리 창작, 예술 작품
- 캐릭터 디자인, 영감 얻기, 창작 과정

[STUDY]
- 학습 방법론, 암기 전략, 노트 정리
- 학습 계획, 집중력 향상, 복습 전략

[EDUCATION]
- 교육 자료 설계, 교수법, 맞춤형 교육
- 커리큘럼 설계, 평가 방법, 학습 동기

[RESEARCH]
- 연구 방법론, 실험 설계, 논문 작성
- 데이터 수집 및 분석, 문헌 조사

[BUSINESS]
- 비즈니스 기획서, 보고서, 사업 전략
- 프로젝트 관리, 협상 전략, 경영 전략

[DESIGN]
- UI/UX 디자인, 그래픽 디자인, 제품 디자인
- 사용자 경험 개선, 브랜드 아이덴티티

[WRITING]
- 에세이, 논설문, 보고서 작성

[ETC]
