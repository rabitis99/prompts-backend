## 📦 전체 패키지 구조

```
org.example.sharedprompts/
│
├── domain/
│   └── auth/
│       ├── AuthUser.java
│       ├── CurrentUser.java
│       └── service/
│           ├── AuthService.java                    (인터페이스)
│           ├── AuthServiceImpl.java                (메인 서비스 - 리팩토링됨)
│           ├── AuthTokenService.java                (토큰 발급/재발급)
│           ├── OAuthLoginFlow.java                  (OAuth 로그인 플로우)
│           ├── SpringPasswordVerifier.java          (비밀번호 검증 구현체)
│           │
│           ├── SignUpService.java                    ✨ 새로 생성
│           ├── LoginService.java                    ✨ 새로 생성
│           └── TokenSecurityService.java            ✨ 새로 생성
│
├── auth/
│   ├── audit/
│   │   └── AuthAuditPublisher.java                  (감사 로그 발행)
│   │
│   ├── security/
│   │   └── token/
│   │       ├── TokenSecurityCheckResult.java        (검증 결과 enum)
│   │       ├── TokenSecurityValidator.java          (보안 검증)
│   │       └── TokenSecurityResultHandler.java      (결과 처리)
│   │
│   └── storage/
│       ├── RefreshTokenMetadata.java                (메타데이터)
│       └── RefreshTokenStore.java                    (저장소 인터페이스)
│
└── domain/
    └── user/
        ├── PasswordVerifier.java                    (비밀번호 검증 인터페이스)
        ├── repository/
        │   └── UserRepository.java                  (사용자 저장소)
        ├── service/
        │   ├── UserRegistrationService.java         (사용자 등록)
        │   └── UserValidationService.java           (사용자 검증)
        └── validator/
            └── PasswordStrengthValidator.java       (비밀번호 강도 검증)
```
